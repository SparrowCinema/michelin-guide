# 米其林全球名录

全球约 2 万家米其林餐厅的中文名录：三星、二星、一星、必比登推介和入选餐厅。可以按大洲、国家、城市逐级筛选，也可以搜索店名、城市或菜系。

## 每家店有什么

- **中文店名**：中国内地、港澳台、新加坡、马来西亚的中文名来自米其林中文官网，是官方名称。其他国家的星级餐厅附了参考译名，页面上标“译名”，不是餐厅自己的中文名，预订和导航请用原名。
- **链接**：米其林官网介绍页、地图（中国内地用高德，其他地区用谷歌地图）、餐厅官网（约 1.67 万家有，多数可在官网预订）。
- 菜系、价位。

## 数据来源

- 餐厅名单、等级、地址、官网：米其林指南官网的公开数据，经开源项目 [michelin-my-maps](https://github.com/ngshiheng/michelin-my-maps) 汇总，更新至 2026 年 10 月 11 日。
- 官方中文名：米其林指南中文官网（简体、香港繁体、台湾繁体版）。
- 各国指南发布时间不同，部分名单已是 2026 或 2027 版。米其林会随时撤下歇业的店，去之前请在米其林指南 App 核对。

## 文件

- `index.html`：页面，直接用浏览器打开或通过 GitHub Pages 访问（需要和 `data.json` 放在同一目录，经网页服务器打开）。
- `data.json`：全部餐厅数据。
- `tools/build.py`：从 michelin-my-maps 的 CSV 重新生成 `data.json`，用法见文件开头。
- `tools/zh_official_names.json`：米其林中文官网的官方中文名（按米其林网址里的餐厅标识对应）。
- `tools/reference_translations.tsv`：星级餐厅的参考译名。
- `tools/cn_mainland_curated.json`：中国内地各指南发布时的中文名单，用来标出本版新上榜的餐厅。

本项目与米其林官方无关，仅供个人查阅。
