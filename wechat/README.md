# 米其林全球名录 · 微信小程序

下载 `downloads/dining-passport-wechat.zip`，解压后直接导入微信开发者工具；项目根目录包含 app.json。填写自己的 AppID，基础库使用 3.8.0 或更新版本。也支持将整个仓库作为项目根目录，根配置指向 wechat/。

## 这次改动针对原网站界面

以网站当前 index.html、upgrade.css、upgrade.js 为参考，移除了此前的卡片式简化界面：

- 名录恢复国家／城市层级、等级徽标、原名、菜系价位、想去／去过／导航行内按钮；餐厅显示名及全部 19,888 条的排序与网站相同。
- 恢复搜索、等级筛选、地区菜系价位标签筛选面板、统计表、分页；直接复用网站搜索与城市中文名模块。
- 自定义底栏复用网站 SVG 原图，顺序以网站源码为准：附近／地图／名录／我的。
- 我的页恢复网站折叠分区，顶部已删除的快捷方块和统计块不再出现。
- 护照复用网站封面文案、地球徽章、酒红与烫金色值、258px 封面、840×600 双页缩放布局、地标线稿和签章；左右滑动翻页。
- 餐厅详情显示与网站相同的照片来源、双语介绍、双语地址、历年评级、参考消费、半星日期笔记和多次用餐卡片。介绍与地址模块是原网站代码的相同副本。
- 旅行地图保留旅行／城市切换、地图边框和说明、旅行餐厅清单。内地坐标使用网站相同转换函数；原始坐标不改动。
- 支持网站文字清单备份格式的导出和导入，以及本机主题设置。

## 验证

在仓库根目录运行：

```
node wechat/tests/parity.cjs
node wechat/tests/verify.cjs
node wechat/tests/flow.cjs
```

检查包括：全部餐厅显示名和顺序与网站一致、共享代码一致、来源数据逐条一致、包大小、半星评分、多餐记录、旅行地图和签章、搜索筛选、备份、WXML 事件。

更新原始数据和共享逻辑：`python3 tools/sync_wechat_sources.py`。
重新导出：`python3 tools/package_wechat.py`。ZIP 内 BUILD-MANIFEST.json 保存每个源码文件的哈希，打包后核对 ZIP 与源码一致。

## 明确的差异和未验证项

此包是原生移植，不能宣称已达到逐像素一致。尚未运行微信开发者工具编译、iOS/Android 真机或截图对比。地图底图、系统导航栏、权限弹窗受微信平台控制，与网页不同。

网站的完整英文界面切换、地图结算海报、路线编排、用户照片和统一云端账户仍未完整移植。当前结算页提供餐厅清单长图，不等同于网站的完整地图海报。外部网页地址目前通过复制打开；个人主体小程序不能将现有网站直接当作可自由嵌入的网页。

图片仍引用原网站的米其林图片地址，需要核对相同数据及图片的使用权限和发布要求。记录暂存本机，清理数据或换设备前请先导出。
