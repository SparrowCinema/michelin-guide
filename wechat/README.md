# 全球美食护照 · 微信小程序开发包（原生）

## 当前状态
可在微信开发者工具中导入并运行的**功能骨架**，不是已上线版本。当前仅含一条**明确标注的演示餐厅**，未复制网站的 2 万家数据。个人数据仅存本机，**不支持跨设备同步**。地图需要微信开发者工具和真机联网验证。

## 保留现有底栏
**名录 / 地图 / 附近 / 我的**，与 `SparrowCinema/michelin-guide` README 所述保持一致；没有擅自改为其他导航。

## 已做
- 名录搜索与详情入口（演示数据）
- 在「我的」创建旅行、餐厅加入旅行
- 「地图」只标注选中旅行内有经纬度的餐厅
- 「附近」经授权定位按球面距离排序
- 想去、去过本地保存

## 上线前必须完成
1. 将原项目 `data.json` 转换为适合小程序分批读取的后端 API；不能将整个大型 JSON 直接打进小程序主包。
2. 配置云开发或其他后端，提供微信登录、每用户隔离的旅行、收藏、历次用餐、半星评分、照片、护照签章及数据同步。
3. 迁移网站现有的完整 UI、筛选、护照设计及个人记录模型；本包目前仅是基础界面。
4. 审核图片和数据的使用授权，确认个人主体可选类目及小程序名称；完成备案和正式发布。
5. 微信开发者工具导入本目录；替换 `project.config.json` 的 `touristappid` 为自己的 AppID；真机测试海外地图和定位权限。
